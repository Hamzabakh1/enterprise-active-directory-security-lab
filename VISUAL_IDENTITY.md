# Visual system

Palette: navy `#07182e`, blue `#102e59`, cyan `#22d3ee`, light blue `#38bdf8`, lavender `#818cf8`, and white. Typography: Segoe UI with Arial fallback.

Each repository includes a 1280 × 320 editable SVG banner and a technical topology diagram. The Mermaid files remain the editable source for architecture, authentication, messaging, identity, security, and recovery flows. The topology is a **reference design**; it is not evidence that the systems were deployed. No vendor logo or icon asset is redistributed.

Real captures belong in `assets/screenshots/` or `docs/screenshots/` and must carry a precise caption, date, source, and verification scope. Keep command output as original text in `tests/evidence/`; do not transform a transcript into a simulated terminal screenshot.
